# More than one home

The app shows one home at a time, chosen at page load. Adding a home never
touches an existing one.

```
src/homes/registry.ts        every home, and which is active   (hand-written)
src/homes/<id>/building.ts   \
src/homes/<id>/fixtures.ts    |  GENERATED by docs/design-export.py --home <id>
src/homes/<id>/furniture.ts   |
src/homes/<id>/plan-sheet.svg/
src/homes/<id>/meta.ts       its name, origin, which checks apply (hand-written)
src/data/{building,fixtures,furniture,sheet}.ts   resolvers -> the active home
```

**Why resolvers.** Forty-one places in the app import the plan data. They all
still say `from '../data/furniture'` and know nothing about homes; only the
resolver knows. That is what made this change safe to land.

**Switching reloads the page.** The derived model, both 3D scenes and the
material libraries are built once at module init. A reload is simpler and
more certain than tearing all of that down live.

**Isolation.** Everything a home accumulates in the browser — style
assignments, material and object libraries, saved renders, palettes — goes
through `storageKey()` and is namespaced per home. API keys stay shared:
they are yours, not the building's. Home 1 keeps its original un-suffixed
keys, so nothing already saved is orphaned.

## Adding a home

1. Author or import it on the CAD side: `CAD/homes/<id>/`
2. Generate its data:
   `python3 docs/design-export.py --cad ../CAD/tools --home <id>`
3. Add one entry to `src/homes/registry.ts` and a `meta.ts` beside its data.

## The rule

Before and after any change to shared code, prove the existing homes did not
move:

```
python3 CAD/tools/golden.py --home om-neeldhara   # must end GOLDEN OK
npx vitest run                                    # must stay green
```

`meta.checks` marks which integrity checks are assertions about a particular
building — the mirror line, the curved-screen spans, the recorded 2D-clash
register, the written brief. A home without those properties omits them and
the suite skips them rather than failing.
